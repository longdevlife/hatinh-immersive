# Reference Sources

## Official Hà Tĩnh / Star Global 3D/360

- Public platform: https://dulichhatinh360.com
- Project viewer: https://platform.starglobal3d.com/smart-tourism-360/du-lich-ha-tinh/
- Official Hà Tĩnh source confirms the smart-tourism 3D/360 platform and direct routes for Thiên Cầm, Thạch Hải, Lộc Hà, and Đá Bạc ECO, plus integration of Nguyễn Du and Ngã ba Đồng Lộc.
- Star Global case study states 146 360-degree ground/aerial views and 170+ 2D images for the Hà Tĩnh project, with narration/audio integration.

Audit rule: public visibility or browser retrieval is discovery evidence only. If the viewer exposes an explicit public download action, the resulting file may enter the demo-only candidate lane; production classification still requires rights evidence accepted by the existing Phase 1C model.

## Existing repository demo packages

`apps/web/public/demo/360` currently contains demo panorama tile packages for parts of Sơn Trang, Thiên Cầm, Nguyễn Du, and Đồng Lộc. These are useful for recovery/reference and demo packaging but do not establish production rights by themselves.
